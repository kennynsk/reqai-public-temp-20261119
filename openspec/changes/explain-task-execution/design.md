## Context

Экран задачи содержит очередь проверки или редактор требований. Кнопка с жуком открывает хронологию для диагностики, в том числе при частичном результате после сбоя независимой проверки.

## Decisions

### Журнал открывается на списке событий

Переиспользовать существующую панель, обновление, пагинацию и раскрытие отдельных записей. На узких экранах панель занимает всю ширину. События отображаются по времени с исходным статусом. Для известных событий и кодов показывать русские подписи. Исходное имя переведённого события доступно при раскрытии. События SSE помечаются как наблюдения текущей вкладки.

### Доступный результат объясняется на экране задачи

Показать, сохранён ли черновик декомпозиции и как продолжить проверку. В исследовании указать, что можно продолжить с сохранёнными требованиями. Открытие и закрытие журнала сохраняют текущее состояние редактора и возвращают фокус к кнопке.

### Сводка для поддержки использует весь снимок трассы

Поле `executionSummary` строится на сервере из авторизованных метаданных до применения курсора хронологии. При копировании использовать разрешённые поля, включая факт и причину отказа, даже если событие ещё не загружено в список. Соблюдать действующие роли при запросе защищённых деталей записи. Если браузер отклонит запись в буфер, показать ту же сводку для ручного копирования.
