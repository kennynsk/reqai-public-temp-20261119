## MODIFIED Requirements

### Requirement: Expandable Debug timeline
При выборе задачи интерфейс SHALL предоставлять кнопку «Журнал задачи» с иконкой жука. Панель SHALL сразу показывать хронологию выполнения. Пользователь SHALL иметь возможность раскрыть запись, обновить журнал и загрузить следующие страницы.

#### Scenario: User opens Debug
- **WHEN** пользователь нажимает кнопку «Журнал задачи»
- **THEN** фокус переходит в панель
- **AND** журнал показывает события по времени с исходным статусом и длительностью при наличии

#### Scenario: User closes Debug
- **WHEN** пользователь нажимает Escape или кнопку закрытия
- **THEN** панель закрывается, фокус возвращается к кнопке «Журнал задачи», состояние задачи сохраняется

#### Scenario: Debug opens on a narrow viewport
- **WHEN** ширины экрана недостаточно для боковой панели
- **THEN** панель занимает ширину экрана, а записи и действия доступны без горизонтальной прокрутки страницы

## ADDED Requirements

### Requirement: Понятные записи журнала
Журнал SHALL показывать русское описание для известных событий и причин, сохраняя исходное техническое имя и метаданные при раскрытии записи с учётом прав доступа.

#### Scenario: Ответ критика отклонён
- **WHEN** событие сообщает о техническом отказе проверки с кодом `SEMANTIC_AUDIT_INVALID`
- **THEN** запись объясняет причину на русском и показывает код

#### Scenario: Повтор проверки завершился успешно
- **WHEN** первая попытка отклонена и последующая проверка прошла
- **THEN** журнал показывает оба события по времени с их собственными исходами

#### Scenario: Браузер потерял связь
- **WHEN** зарегистрировано отключение или переподключение в текущей вкладке
- **THEN** журнал помечает запись как наблюдение текущей вкладки

### Requirement: Продолжение работы после частичного результата
Экран задачи SHALL объяснять, что доступно для продолжения работы с требованиями после частичного результата.

#### Scenario: Сохранён черновик декомпозиции
- **WHEN** декомпозиция завершилась частично и доступен черновик
- **THEN** экран сообщает, что черновик сохранён, и показывает очередь и редактор согласно состоянию задачи

#### Scenario: Исследование завершилось частично
- **WHEN** после сбоя исследования доступна сохранённая входная версия
- **THEN** экран предлагает продолжить с сохранёнными требованиями и показывает редактор

### Requirement: Безопасная сводка для поддержки
Панель SHALL давать возможность скопировать сводку с ID задачи, статусом и исходом, этапом, безопасными кодами, длительностью, моделью и версиями инструкций при наличии.

#### Scenario: Копирование сведений для поддержки
- **WHEN** пользователь нажимает «Скопировать для поддержки»
- **THEN** в буфер попадают только разрешённые служебные поля
- **AND** сводка исключает материалы, тексты требований, промпты, стек, секреты и произвольный JSON событий

#### Scenario: Ограниченный доступ к техническим данным
- **WHEN** панель открывает владелец без привилегий на защищённые сведения
- **THEN** доступна безопасная сводка, а запросы защищённых подробностей проверяются сервером

#### Scenario: Буфер обмена недоступен
- **WHEN** браузер отклоняет запись в буфер обмена
- **THEN** панель предлагает выделить ту же безопасную сводку вручную
