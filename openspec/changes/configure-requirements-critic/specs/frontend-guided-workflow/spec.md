## ADDED Requirements

### Requirement: Выбор независимой проверки при запуске
«Настройки AI» SHALL позволять управлять независимой проверкой для новых запусков декомпозиции и исследования. По умолчанию проверка SHALL быть включена. Выбор SHALL восстанавливаться в том же браузере для того же пользователя.

#### Scenario: Пользователь отключает критика
- **WHEN** пользователь выключает независимую проверку и запускает задачу
- **THEN** браузер передаёт выбранное состояние вместе с параметрами запуска
- **AND** текущее состояние открытого результата остаётся доступно для редактирования
