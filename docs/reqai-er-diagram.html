Как база связывает задания, артефакты и результаты

Основная модель данных асинхронной платформы. Фокус — путь пользовательского ввода через обработку к декомпозиции, исследованию и сохранённым версиям требований.

DATA PATH

Путь пользовательского ввода

  • INPUT артефакт содержит исходный текст или файл.
  • INTERMEDIATE хранит чанки и ответы отдельных шагов.
  • RESULT хранит итоговый JSON с декомпозицией или исследованием.

SUPPORTING TABLES

Служебный контур

  • idempotency_keys, job_dependencies
  • webhook_deliveries, consumed_events
  • operational_state, model_circuit_state, model_leases
  • schema_migrations — журнал миграций

SECURITY

Tenant isolation
